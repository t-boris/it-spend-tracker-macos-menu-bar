## Statement

The user shall be able to attach free-text tags to tracked services (including manual services), keys, and every provider breakdown item the app displays, using one shared tag vocabulary kept only inside the app.

## Acceptance Criteria

- [x] Users can add and remove free-text tags on a tracked service, including a manual service.
- [x] Users can add and remove free-text tags on existing keys and on every provider breakdown item the app displays: account, project and line-item rows, and Neon projects (DEC-025).
- [x] Existing tags are suggested when tagging any target type.
- [x] Tag input trims whitespace, ignores empty entries and deduplicates case-insensitively.
- [x] Assignments are independent: tagging a service does not tag its keys or items, and the reverse.
- [x] Tags stay local: nothing is written to or read from the provider.
