## Statement

The Tags view shall list every tagged target with its type, parent service and current-month amount, let the user open the target, and let the user edit the tags of any listed target, including one that is currently missing.

## Acceptance Criteria

- [x] The Tags view lists each tagged target with its type, its parent service and its current-month amount, or "unavailable".
- [x] Each row opens the relevant service, key or breakdown section; a target that is currently missing opens its parent service.
- [x] Every row has an "Edit tags…" action, also for a missing target, so a stale assignment can be removed (DEC-037).
