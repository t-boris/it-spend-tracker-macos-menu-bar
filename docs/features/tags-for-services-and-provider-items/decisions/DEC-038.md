## Context

The main feature limits tags to keys: REQ-013 ("tag keys", "summed over its keys") and DEC-024 ("any key of any API-connected service"). The overview and plan of this feature widen tags to services and provider items and change the totals rule. Records checked: REQ-013, REQ-015, REQ-016, DEC-024, DEC-027 and discussion.md of it-spend-tracker-macos-menu-bar.

## Alternatives

1. Edit REQ-013 and DEC-024 of the verified main feature to the new wording

## Decision

This feature extends, and where they differ replaces, the key-only scope of DEC-024 and the wording of REQ-013 of the main feature. Key tags keep working unchanged and become one target kind of the shared vocabulary. The totals rule of REQ-013 criterion 3 ("summed over its keys") is replaced by REQ-004 of this feature. Main-feature records are not edited by this change; the main feature's REQ-013 and DEC-024 stay as the history of the first release.

## Reason

The main feature is already verified; its records describe what was true when it was accepted, and reopening them is the owner's call. This feature's records are the current rule.

## Consequences

Readers of the main feature's REQ-013 must follow this decision to the current behavior. Marked proposed for the owner to accept.
