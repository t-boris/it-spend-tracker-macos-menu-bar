## Context

DEC-007 adds token usage per service and per key, and DEC-008 makes it informational only (excluded from totals). The last AI message in discussion.md asked whether tokens are shown as a single number or with an input/output and per-model breakdown; the question was not answered.

## Alternatives

1. Input/output (and cached, when given) tokens, broken down by model
2. A single total token count
3. Input/output totals without a per-model breakdown

## Decision

Where a connector exposes token usage, the app shows, per service and per key, the current month's input, output and (when the provider reports it) cached input tokens, broken down by model, plus a total. Where the provider does not expose token usage, the panel shows 'no data'. Token usage never contributes to spend figures (DEC-008).

## Reason

The user chose the detailed breakdown.

## Consequences

Connectors that expose usage must return per-model, per-key token rows; the data model stores token usage per service, key, model and month.
