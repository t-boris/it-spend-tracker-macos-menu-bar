## Context

The user buys prepaid credits/tokens from some providers and wants them tracked in addition to money spent. Options were A (purchases only), B (purchases + balance/consumption), C (B + token usage per service/key).

## Alternatives

1. A: Record credit purchases only (date, USD amount, volume, service)
2. B: Purchases plus purchased/consumed/remaining balance
3. C: B plus token usage per service and per key where the provider exposes it

## Decision

v1 records prepaid credit purchases (date, USD amount, volume, service; manual or via API), shows purchased/consumed/remaining balance, and shows token usage per service and per key where the provider exposes it; otherwise shows 'no data'. How purchases vs. consumption count toward monthly totals is still open.

## Reason

The user chose option C to get the full picture, including when credits will run out and token consumption.
