## Decision

`scripts/install.sh` builds a Release app, installs it to `/Applications/IT Spend Tracker.app`, relaunches it and registers it as a login item (SMAppService). The app registers itself at first launch; Settings has a "Launch at login" toggle. The Keychain items stay valid across reinstalls because the app is signed ad hoc with a stable identifier.

## Consequences

Later updates: run `scripts/install.sh` again.
