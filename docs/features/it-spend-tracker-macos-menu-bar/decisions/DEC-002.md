## Context

Q-003: whether v1 should proactively warn about budget overruns or keys expiring soon.

## Alternatives

1. Monthly budgets with macOS notifications
2. Visual indicators in the panel only
3. Defer all alerting to a later version

## Decision

v1 shows warnings only as visual indicators inside the menu bar panel (e.g. key expiring soon, notable spend increase). It sends no macOS system notifications and has no budgets.

## Reason

Keeps v1 small while still surfacing problems when the user opens the panel.

## Consequences

Warnings can be missed if the panel is not opened. Budgets and system notifications stay out of scope and can be added later. Indicator thresholds still need to be defined.
