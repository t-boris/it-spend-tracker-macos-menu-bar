## Context

The fixed-size menu bar panel is too small to see the whole picture.

## Alternatives

1. "Open in window": a normal resizable window with the same content
2. A larger or resizable panel

## Decision

The panel has an "Open in window" action that opens a normal, resizable (full-screen capable) window with the same content and larger charts. The menu bar panel remains the quick view. The app still has no Dock icon when the window is closed.

## Reason

The user chose a separate window.

## Consequences

Both views share the same data and update together.
