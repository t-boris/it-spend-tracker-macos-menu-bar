## Context

The user wants to see "how it works inside" a service, not only its total.

## Alternatives

1. By model / line item
2. By provider project (OpenAI project, Anthropic workspace)
3. Usage vs subscription split

## Decision

All three. Where the provider API allows, connectors return monthly usage cost grouped by line item (model and cost type) and by provider project, for the same range as the daily costs (falling back to the current month, or to "no data", when the provider rejects the grouping for older ranges). The service page shows both breakdowns for a selectable month, and the split usage · subscriptions · total (DEC-026). OpenAI: `group_by` line_item and project_id; Anthropic: `group_by` description and workspace_id with workspace names; Vercel: FOCUS ServiceName and project tags; Google Cloud: service and project from the billing export.

## Reason

The user chose all breakdowns.

## Consequences

Breakdown rows are stored per service, month, dimension and label, and are replaced for refreshed months.
