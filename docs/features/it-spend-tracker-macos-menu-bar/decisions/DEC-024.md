## Context

The user wants to label keys (e.g. by project) to see what each project costs; provider keys carry only provider-side projects/workspaces.

## Alternatives

1. Own free-text tags on keys with per-tag totals across services
2. Group by provider projects only
3. Both

## Decision

The user can assign any number of free-text tags to any key of any API-connected service. Tags are stored locally per service and key ID, survive refreshes, and are deleted with the service. The panel shows, per tag, the current-month spend summed over its keys across all services, and lists the keys; keys whose provider does not expose per-key spend are listed as "unavailable" and not added.

## Reason

The user chose own tags with totals across services.

## Consequences

Per-tag totals cover the current month only, because per-key spend is available only for the current month (SRC-002).
