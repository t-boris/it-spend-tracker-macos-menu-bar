## Context

The AI onboarding assistant needs access to Claude or Codex (DEC-003).

## Alternatives

1. Local CLI (Claude Code / Codex CLI) using the user's subscription
2. Direct API calls with the user's Anthropic/OpenAI API key
3. Support both, selectable in settings

## Decision

The app invokes the locally installed and authenticated Claude Code or Codex CLI, using the user's existing subscription.

## Reason

No extra API key or separate API billing; reuses subscriptions the user already pays for.

## Consequences

The CLI must be installed and signed in; the app depends on CLI behavior and must handle its absence gracefully. No AI API secret is stored.
