## Context

Many services (e.g. ChatGPT Plus) do not expose spend via API, so v1 would otherwise miss part of the user's IT spending.

## Alternatives

1. Manual subscription entry (amount, period) alongside API services
2. Support only services with billing APIs
3. Import from invoices/emails or bank statements

## Decision

v1 supports manual entry of subscriptions (name, amount, billing period) shown alongside API-connected services.

## Reason

Gives a complete spending picture with low complexity; import from invoices/bank data is a separate large effort.

## Consequences

User maintains manual entries themselves; totals and history must normalize billing periods to months; invoice/bank import stays out of v1.
