## Context

With DEC-025 the fixed-size menu bar panel stayed the main view and the resizable window was reachable only from the panel's home screen. Service pages, forms and settings opened inside the small panel, which cannot be resized. The user: "Оно маленькое окошко для таких вещей ... Я не могу даже увеличить его."

## Alternatives

1. Panel as overview; details always in the big window
2. Everything in the window; no panel
3. "Open in window" button on every panel page

## Decision

Clicking the menu bar icon opens the app's single main window (or brings it to the front); clicking it again while the window is in front hides it. The window is a normal, resizable, full-screen-capable window that remembers its size and position, and contains all views (services, history, tags, service pages, add service, settings). There is no popover panel. The menu bar icon still shows the warning cue (REQ-008), and the app still has no Dock icon.

## Reason

The user chose to have everything in the window.

## Consequences

DEC-025 is superseded. REQ-001 ("clicking the icon opens a panel") and REQ-014 are updated accordingly. The menu bar item is an AppKit status item, since SwiftUI's MenuBarExtra only supports a popover or a menu.
