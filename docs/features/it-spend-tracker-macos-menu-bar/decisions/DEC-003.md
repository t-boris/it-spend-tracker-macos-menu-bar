## Context

The onboarding assistant (and any other AI feature) needs an AI backend; privacy and quality trade-offs were considered.

## Alternatives

1. Cloud model via user's own API key (generic OpenAI/Anthropic)
2. Local model
3. No AI: built-in instructions for known services

## Decision

All AI features use Claude or Codex, selectable by the user. Credential values are never sent to the AI.

## Reason

The user explicitly chose Claude or Codex for all AI tasks.

## Consequences

Onboarding requires network access to the chosen AI provider; service names and non-secret context leave the Mac. How the app accesses Claude/Codex (installed CLI vs API key) remains to be decided.
