## Context

The specification did not fix a tech stack or persistence library for the native menu bar app and "local database" (DEC-013).

## Alternatives

1. Apple frameworks only (SwiftUI, SwiftData, Swift Charts, Security, URLSession)
2. Same, but GRDB.swift (third-party) for SQLite

## Decision

Swift 6 with SwiftUI `MenuBarExtra` (window style) as a menu-bar-only app (`LSUIElement`), SwiftData stored in the app's Application Support directory, Swift Charts for history, Security.framework Keychain for secrets, URLSession for provider APIs, and Foundation `Process` for the Claude Code / Codex CLI. The Xcode project is generated with XcodeGen from `project.yml`. Minimum macOS 15. No third-party packages.

## Reason

The user approved the dependency-free Apple stack.

## Consequences

Adding any third-party library needs a new decision.
