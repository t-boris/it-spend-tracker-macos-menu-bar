## Context

REQ-004 does not say whether past months are fetched on connection or how long history is kept.

## Alternatives

1. Backfill from the API
2. Tracking only from the connection date

## Decision

On connection, each connector backfills monthly spend for up to the previous 12 months where the provider API allows; otherwise history starts at the connection date and earlier months show 'no data'. Stored history is kept indefinitely until the service is removed.

## Reason

Immediate trend visibility supports the keep/cancel decision; data volume is tiny so retention limits are unnecessary.

## Consequences

Connectors declare backfill depth; REQ-004 criteria are updated to distinguish zero spend from missing data.
