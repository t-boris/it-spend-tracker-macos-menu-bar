## Context

REQ-006 does not name the secret storage mechanism, spend data protection or deletion behavior.

## Alternatives

1. Keychain
2. Encrypted local file

## Decision

All credentials are stored in the macOS Keychain, scoped to the app. Spend data is stored in a local database in the app's Application Support container without app-level encryption, relying on OS disk encryption. Removing a service, after confirmation, deletes its Keychain items and all its stored spend, key, credit and history data.

## Reason

Keychain is the platform standard and avoids custom key management; spend figures are low sensitivity for a personal app.

## Consequences

REQ-006 criteria are updated; removed services disappear from past history and totals.
