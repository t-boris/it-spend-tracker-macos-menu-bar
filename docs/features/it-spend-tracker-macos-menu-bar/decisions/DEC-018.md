## Context

DEC-016 was recorded as accepted but explicitly marked "AI-proposed resolution pending user confirmation". When asked to confirm, the user chose Russian and English instead of Russian only.

## Alternatives

1. Russian-only UI (DEC-016)
2. Russian and English UI

## Decision

v1 ships a Russian and an English UI. The app follows the macOS preferred language (Russian when the system prefers Russian, otherwise English as the development language); there is no in-app language switcher. All user-facing strings live in an Xcode String Catalog with both translations. Provider names, key names and technical terms are shown as-is. The AI onboarding prompt asks the assistant to answer in the app's current UI language. Amounts are USD, formatted with the current locale's conventions for numbers and dates.

## Reason

The user explicitly chose both languages.

## Consequences

DEC-016 is superseded. Every string needs a Russian and an English translation; acceptance checks verify that both localizations are complete.
