## Summary

The user's original request for a personal macOS menu bar app that tracks spending on IT and AI services (Fly.io, Google/Firebase, Vercel, Neon, OpenAI/ChatGPT, Anthropic). It shows spend per service and per key, with key metadata, totals, and monthly history, so the user can decide which services to keep. An AI assistant guides the user through connecting each new service. The app is local-only and never exposed externally.

intake
