## Statement

The app runs as a macOS menu bar app; clicking its icon opens a resizable window showing all services and spending (DEC-029).

## Acceptance Criteria

- [x] App icon is visible in the macOS menu bar; the app has no Dock icon
- [x] Clicking the icon opens (or brings to the front) the main window with the service list and total spend; clicking again while it is in front hides it
- [x] The app works without any externally exposed server or web UI
- [x] Installed in /Applications and launched at login; Settings has a "Launch at login" toggle (DEC-037)
- [x] All UI text is available in Russian and English and follows the macOS preferred language (DEC-018)
