## Statement

The user can add, edit and remove manually entered services (subscriptions) with a name, amount in USD and billing period, for services that expose no billing API; these appear alongside API-connected services.

## Acceptance Criteria

- [ ] User can create, edit and delete a manual subscription with name, USD amount and billing period
- [ ] Manual subscriptions appear in the service list and are included in totals and monthly history
- [ ] Amounts are displayed in USD
