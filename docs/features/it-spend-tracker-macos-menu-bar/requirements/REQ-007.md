## Statement

The user can add, edit and remove manually entered services, and can add any number of fixed subscriptions (name, amount in USD, billing period monthly or yearly, start date and optional end date) to any service, including API-connected ones (DEC-026). The user can also record prepaid credit purchases manually (REQ-010).

## Acceptance Criteria

- [x] User can create, edit and delete subscriptions with name, USD amount, billing period (monthly/yearly), start date and optional end date on any service, several per service
- [x] Each charge counts in the month it falls due until the end date; a yearly subscription counts in full in its renewal month
- [x] The service page lists subscription payments with their dates (last 12 months) and the next payment date and amount; the history chart shows subscription payments separately from usage so payment spikes are visible
- [x] Changing the amount creates a new price effective from a chosen date; earlier months keep the old amount
- [x] Manual subscriptions appear in the service list and are included in totals and monthly history
- [x] Amounts are displayed in USD
