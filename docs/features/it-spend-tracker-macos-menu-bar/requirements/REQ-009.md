## Statement

The app refreshes spending data from API-connected providers automatically in the background on a schedule (every few hours) and also when the user presses a Refresh button in the panel. The panel shows cached data immediately and indicates when each service was last updated successfully.

## Acceptance Criteria

- [x] While the app is running, spending data for all API-connected services is refreshed automatically every 4 hours without user action.
- [x] A refresh also runs on app launch and after the Mac wakes from sleep when the last successful refresh is older than 4 hours.
- [x] The panel has a Refresh button that triggers an immediate refresh of all API-connected services.
- [x] Opening the panel shows the last cached data immediately, without waiting for a refresh.
- [x] Each service shows the time of its last successful update.
- [x] If refreshing a service fails, the panel keeps its last known data and marks the service with an error indicator; other services are unaffected.
