## Statement

The app refreshes spending data from API-connected providers automatically in the background on a schedule (every few hours) and also when the user presses a Refresh button in the panel. The panel shows cached data immediately and indicates when each service was last updated successfully.

## Acceptance Criteria

- [ ] While the app is running, spending data for all API-connected services is refreshed automatically at a fixed interval of a few hours without user action.
- [ ] The panel has a Refresh button that triggers an immediate refresh of all API-connected services.
- [ ] Opening the panel shows the last cached data immediately, without waiting for a refresh.
- [ ] Each service shows the time of its last successful update.
- [ ] If refreshing a service fails, the panel keeps its last known data and marks the service with an error indicator; other services are unaffected.
