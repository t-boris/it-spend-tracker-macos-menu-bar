## Statement

When the user names a service (and account identifier), an AI assistant identifies the service, explains which credentials are needed and how to obtain them, and guides the connection. The assistant runs through a locally installed and authenticated CLI (Claude Code or Codex CLI, user's choice) using the user's existing subscription; no separate AI API key is required. Credential values are never sent to the AI.

## Acceptance Criteria

- [x] The user can add a service by naming it and asking the assistant in one action; the assistant determines which keys or tokens are needed and gives step-by-step instructions with direct links to the pages where they are created (links are clickable).
- [x] The user can choose Claude Code CLI or Codex CLI as the assistant backend in settings.
- [x] The app uses the selected CLI installed on the Mac and requires no AI API key.
- [x] If the selected CLI is not installed or not authenticated, the app tells the user and explains how to install/sign in; manual service setup remains available.
- [x] Credential values entered by the user are never included in prompts, CLI arguments, the CLI environment or any file the CLI can access.
- [x] The CLI runs non-interactively from an empty temporary working directory with all tools disabled, except web search/fetch when researching a service without a built-in connector (DEC-022), and receives only the service name, account identifier, the user's note and connector metadata (DEC-011).
- [x] CLI output is displayed as guidance text or parsed as a declarative connector definition (REQ-012); it is never executed.
- [x] Credentials are entered only in native form fields defined by the matched built-in connector; a service without a built-in connector gets an AI-proposed connector (REQ-012) or manual entry.
