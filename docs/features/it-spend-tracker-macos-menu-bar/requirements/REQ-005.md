## Statement

When the user names a service (and account identifier), an AI assistant identifies the service, explains which credentials are needed and how to obtain them, and guides the connection. The assistant runs through a locally installed and authenticated CLI (Claude Code or Codex CLI, user's choice) using the user's existing subscription; no separate AI API key is required. Credential values are never sent to the AI.

## Acceptance Criteria

- [ ] The user can choose Claude Code CLI or Codex CLI as the assistant backend in settings.
- [ ] The app uses the selected CLI installed on the Mac and requires no AI API key.
- [ ] If the selected CLI is not installed or not authenticated, the app tells the user and explains how to install/sign in; manual service setup remains available.
- [ ] Credential values entered by the user are never included in prompts sent to the CLI.
