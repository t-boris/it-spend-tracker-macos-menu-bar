## Statement

The user can ask the local AI assistant questions about the collected spending data and get answers based on it.

## Acceptance Criteria

- [x] A "Chat" section in the window accepts a question and shows the answer; earlier turns of the session are shown and sent along
- [x] The prompt contains only the app's data snapshot and the conversation; no credential values, key secrets or hints
- [x] The CLI runs with all tools disabled, as for onboarding; the answer is never executed
- [x] If the CLI is missing or signed out, the same guidance as in Settings is shown
