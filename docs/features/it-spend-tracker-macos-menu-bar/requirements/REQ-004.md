## Statement

The app stores and displays how spending changed month by month per service and in total, including manually entered subscriptions.

## Acceptance Criteria

- [x] History shows per-month spend for each service and the total.
- [x] Manual subscriptions appear in the months their charges fall due, based on start date, billing period, end date and the price effective at that date (DEC-014).
- [x] On connection, a connector backfills up to the previous 12 months where the provider API allows it; months before available data show "no data" (DEC-015).
- [x] A month with zero spend is shown as 0 USD and is visually distinct from a month with no data.
- [x] History is kept until the service is removed.
