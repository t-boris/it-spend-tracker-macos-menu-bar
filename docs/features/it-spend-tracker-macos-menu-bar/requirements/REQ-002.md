## Statement

The app shows spend in USD for each service, whether API-connected or manually entered, and a total in USD across a user-selected set of services.

## Acceptance Criteria

- [ ] Each service shows its current-month spend in USD
- [ ] User can select which services are included in the total
- [ ] The total equals the sum of the selected services' USD spend
