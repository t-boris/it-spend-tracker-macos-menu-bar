## Statement

All credentials and spending data are stored only on the user's Mac; secrets are stored securely.

## Acceptance Criteria

- [ ] Credentials (API keys, tokens, passwords, key hints) are sent only to the provider they belong to; they never reach the local AI assistant (prompt, arguments, environment, files) or any other service (DEC-041)
- [ ] The local AI assistant receives only what the user's action needs: for onboarding the service name, account identifier, note and connector metadata; for the spending chat the question, the conversation and the app's data snapshot; for an invoice import the text of the chosen PDF, only after the user agrees to it for that file; no other service receives spend data (DEC-041)
- [x] Secrets are stored only in the macOS Keychain and never in plain text (database, preferences, logs or files)
- [x] Spend data is stored in a local database in the app's Application Support directory
- [x] Removing a service requires confirmation and deletes its Keychain items and all its stored spend, key, credit, token and history data
