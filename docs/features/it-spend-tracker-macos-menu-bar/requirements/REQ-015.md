## Statement

A service page shows how its cost is composed: usage vs subscriptions, and usage by model/line item and by provider project, per month.

## Acceptance Criteria

- [x] The service page shows usage, subscriptions and total for the selected month
- [x] For connectors that provide it, usage is broken down by model/line item, by provider project and (GitHub) by account/organization for the selected month, with previous months selectable
- [x] Breakdowns a provider does not provide show "no data"; a rejected grouping never fails the refresh
