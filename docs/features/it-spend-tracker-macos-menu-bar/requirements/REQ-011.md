## Statement

v1 ships built-in connectors for OpenAI, Anthropic, Vercel, Google Cloud/Firebase (BigQuery billing export), GitHub (DEC-028), Neon (usage metrics with an approximate cost, DEC-031, DEC-033) and Cline (DEC-040). Fly.io has no usable spend API (SRC-002) and, per DEC-012, is added as a manual service (for example from its invoices), like any service without a connector. Each connector declares which data it provides; everything else shows "no data".

## Acceptance Criteria

- [x] OpenAI (admin key): daily spend with up to 12 months backfill, per-key name/last used/expiry/spend, token usage by key and model
- [x] Anthropic (admin key): daily spend with up to 12 months backfill, per-key name/created/expiry (last used and per-key spend shown as unavailable), token usage by key and model
- [x] Vercel (access token, optional team ID): daily spend from billing charges (`EffectiveCost`, which includes the plan fee; ranges without data are "no data") with up to 12 months backfill, token name/last active/expiry (per-token spend unavailable)
- [x] Google Cloud/Firebase (one service-account JSON key, one or more export datasets): daily net spend (cost + credits) in USD from all standard export tables found, broken down by service, project and billing account (DEC-034); API keys with their request counts and approximate cost (REQ-016, DEC-035, DEC-036)
- [x] Every service page links to the provider's billing and key-management consoles (DEC-035)
- [x] A prepared connection file can be imported once at launch; its secrets go to the Keychain and the file is deleted
- [x] GitHub (personal access token, username): daily net spend of the personal account and every readable organization (DEC-032), broken down by account/organization, repository and product/SKU; unreadable organizations are listed with the reason; fixed plans are added as subscriptions
- [x] Neon (API key): monthly usage metrics per organization and project (DEC-031, REQ-017) with an approximate cost from plan rates that is counted as spend and marked ≈ (DEC-033)
- [x] Cline (in-app sign-in, no key, DEC-040): daily spend = Cline credits used (personal account and the user's own usage in each Cline organization) + Cline Pass payments, with up to 12 months backfill, broken down by model and, when organizations exist, by account; token usage by model for the current month; credit top-ups imported as purchases (informational); the provider-reported balance kept as the balance snapshot; an ended session asks the user to sign in again and keeps the data
- [x] Connector notes are shown as warnings (fixable) or neutral information, and each can be hidden and shown again
- [x] Fly.io and any other service are offered an AI-proposed connector (REQ-012) or manual entry
- [x] Provider-reported usage cost is the connected service's spend (DEC-023)
