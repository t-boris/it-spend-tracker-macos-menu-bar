## Statement

For connectors that report usage but not money (Neon), the service page shows usage metrics per month, in total and by project, while spend comes from subscriptions.

## Acceptance Criteria

- [x] Neon usage is shown per selectable month: compute (CU-hours), storage (GB-months by type), transfer (GB) and extra branches (branch-months), in total and per project
- [x] Units follow Neon's documented conversions (decimal GB)
- [x] Next to usage, the Neon page shows an approximate cost (≈) per metric, project and month from the plan rates minus allowances (DEC-033), including a monthly history; it is counted as Neon's spend in totals, history and warnings, and every figure containing it is marked ≈
