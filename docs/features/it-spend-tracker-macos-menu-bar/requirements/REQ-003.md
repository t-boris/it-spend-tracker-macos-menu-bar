## Statement

For services that use API keys, the app shows each key with its name, last-used time, expiry, and spend where the provider exposes this data.

## Acceptance Criteria

- [ ] Keys are listed under their service
- [ ] Name, last used, expiry and spend are shown when available
- [ ] Fields the provider does not expose are shown as unavailable, not as zero
