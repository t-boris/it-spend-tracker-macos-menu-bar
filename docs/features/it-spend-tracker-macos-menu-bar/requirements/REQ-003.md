## Statement

For services that use API keys, the app shows each key with its name, last-used time, expiry, and spend where the provider exposes this data.

## Acceptance Criteria

- [x] Keys are listed under their service
- [x] Name, last used, expiry and spend are shown when available
- [x] Fields the provider does not expose are shown as unavailable, not as zero
- [x] Per-key token usage is shown as described in REQ-010 when the provider exposes it
- [x] Each key opens its detail page (REQ-016)
