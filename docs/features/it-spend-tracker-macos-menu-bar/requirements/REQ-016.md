## Statement

Every key has a page showing everything the provider reports about it, plus its cost history and token usage where available.

## Acceptance Criteria

- [x] Selecting a key opens its page: service, project/workspace, masked value, owner, status, scopes/origin, created, last used, expiry with the 14-day warning, and tags (editable)
- [x] The page shows the key's current-month cost and share of the service's usage, and cost by month for as far back as the provider allows
- [x] The page shows this month's token usage for the key by model (input, cached, output, requests when reported)
- [x] Facts the provider does not report show "unavailable", never zero
- [x] Google API keys show requests this month (Cloud Monitoring) and allowed APIs (DEC-035)
- [x] Google keys show an approximate (≈) month cost = project/service cost × the key's share of requests to that service (DEC-036)
- [x] Every key links to its page in the provider console, or to the provider's key list
