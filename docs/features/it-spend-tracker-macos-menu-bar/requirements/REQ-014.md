## Statement

All views live in one resizable main window opened from the menu bar icon; there is no fixed-size panel (DEC-029).

## Acceptance Criteria

- [x] Service pages, key pages, add service, settings, history and tags all open inside the main window
- [x] A sidebar always lists Services, History, Tags, every service, Add service and Settings, so any view is one click away (no back navigation needed)
- [x] The window is resizable (including full screen), remembers its size and position, and its charts grow with it
