## Statement

The user can tag keys and see what each tag costs across services.

## Acceptance Criteria

- [x] The user can add and remove free-text tags on any key of an API-connected service; existing tags are offered for reuse
- [x] Tags survive refreshes and are deleted when the service is removed
- [x] A tags view shows each tag's current-month spend summed over its keys across all services, with the keys listed
- [x] Keys without provider per-key spend are listed as "unavailable" and not added to the tag total
