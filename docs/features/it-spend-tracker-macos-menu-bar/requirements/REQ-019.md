## Statement

The user can look at spend day by day over a chosen recent range, see whether it is rising or falling, and see an approximate total for the current month.

## Acceptance Criteria

- [x] History offers ranges of 30, 60 and 90 days next to the existing 12-month view; the choice is remembered
- [x] A daily chart shows spend per day stacked by service with a 7-day average line; hovering a day shows its total and per-service amounts
- [x] The last N full days are compared with the N days before them, in total and per service, with the change in percent
- [x] The current month shows spend so far, a ≈ forecast for the whole month and last month's total; a cumulative chart compares this month with last month and draws the forecast to month end
- [x] Days without provider data are "no data", not zero; a service without enough data has no forecast and is named
- [x] The forecast method is explained on the page (DEC-039)
