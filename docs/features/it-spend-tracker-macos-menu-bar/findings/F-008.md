## Finding

The spec does not say whether history for past months is fetched from provider APIs when a service is connected, or only built up from the date the app starts tracking. It also does not say how long history is kept.

> History shows per-month spend for each service and the total.

## Possible interpretations

- Backfill from the API
- Tracking only from the connection date

## Resolution

AI: При подключении подтягиваем историю из API за последние 12 месяцев, где провайдер это позволяет, иначе — с даты подключения; история хранится бессрочно, пока сервис не удалён. — see DEC-015.
