## Finding

Agentic CLIs can read files and run tools. The spec does not say how the CLI is sandboxed (for example, no tool access and no Keychain access), or where the user enters credentials: in a native app form, never in the chat. It also does not define how the AI output becomes a configured connector for an arbitrary service.

> The user can choose Claude Code CLI or Codex CLI ... Credential values are never sent to the AI.

## Possible interpretations

- The AI only gives instructions, and connectors are built in per provider
- The AI generates the API call config dynamically

## Resolution

AI: AI только даёт инструкции: CLI запускается неинтерактивно без инструментов (tools отключены, отдельная пустая рабочая папка), учётные данные вводятся только в нативную форму приложения и сохраняются в Keychain; подключение выполняют встроенные коннекторы. — see DEC-011.
