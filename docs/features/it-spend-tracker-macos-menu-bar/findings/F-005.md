## Finding

Fetching billing data needs provider-specific integrations. Unknowns (unverified): some providers (e.g. Anthropic, OpenAI) have admin/usage APIs that need admin keys. Per-key expiry/last-used data is available only on some providers, and Google Cloud billing needs a BigQuery export. The spec does not say which providers v1 supports or what happens for a service with no connector (fall back to manual entry?).

> an AI assistant identifies the service ... and guides the connection

## Possible interpretations

- A fixed list of v1 connectors
- Any service with a generic connector

## Resolution

AI: Фиксированный список коннекторов v1: OpenAI, Anthropic, Vercel, Neon, Fly.io, Google Cloud/Firebase (через BigQuery billing export); всё прочее — ручной ввод. Доступность API каждого провайдера нужно проверить до реализации. — see DEC-012.
