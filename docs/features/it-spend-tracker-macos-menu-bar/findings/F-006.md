## Finding

The spec does not name the storage mechanism: the macOS Keychain or app-level encryption. It also does not say whether spend data is encrypted, or how data is deleted when a service is removed.

> Secrets are not stored in plain text

## Possible interpretations

- Keychain
- Encrypted local file

## Resolution

AI: Секреты — только в macOS Keychain; данные о расходах — в локальной базе в Application Support без отдельного шифрования (защита FileVault); при удалении сервиса удаляются его секреты и данные после подтверждения. — see DEC-013.
