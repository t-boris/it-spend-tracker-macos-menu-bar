## Question

Как обрабатывать расходы в разных валютах (например, API в USD, подписки в EUR/RUB)?

## Why it matters

От этого зависит корректность итоговых сумм и истории по месяцам.

## Options

- **A**: Всё только в USD; ручные подписки вводятся в USD
- **B**: Каждая запись в своей валюте, итог в выбранной базовой валюте по курсу
- **C**: Итоги отдельно по каждой валюте, без конвертации

## Answer

A. Всё только в USD; ручные подписки вводятся в USD
