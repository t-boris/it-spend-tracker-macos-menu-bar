## Question

Как и когда приложение должно обновлять данные о расходах у провайдеров?

## Why it matters

Определяет основной сценарий, актуальность цифр в панели и поведение при ошибках API.

## Options

- **A**: Автоматически в фоне по расписанию (например, раз в несколько часов) + кнопка «Обновить»
- **B**: При открытии панели (с кешем) + кнопка «Обновить»
- **C**: Только вручную по кнопке «Обновить»

## Answer

A. Автоматически в фоне по расписанию (например, раз в несколько часов) + кнопка «Обновить»
